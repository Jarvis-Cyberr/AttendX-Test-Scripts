# AttendX-Test-Scripts

Automation test scripts for the AttendX Student Attendance App.

## Scripts
- `test_login.py` - verifies a student can log in with valid credentials.
- `test_attendance.py` - verifies a student attendance can be marked and saved.

## Requirements
- Python 3, Selenium (pip install selenium), Chrome and ChromeDriver

## Run
- python test_login.py
- python test_attendance.py
